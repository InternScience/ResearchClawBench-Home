# Research Plan: HEEW Mini-Dataset Analysis

## Goal
Comprehensive analysis of the HEEW Mini-Dataset covering data quality, hierarchical aggregation, correlation analysis, clustering, and time-series patterns.

## Phases

### Phase 1: Data Exploration & Cleaning [ ]
- Load all 13 CSV files
- Check data quality (missing values, outliers, duplicates)
- Implement data cleaning algorithms
- Export cleaned dataset

### Phase 2: Hierarchical Aggregation Verification [ ]
- Verify BN001-BN010 sum equals CN01
- Verify CN01 equals Total
- Quantify aggregation errors

### Phase 3: Statistical Analysis & Correlation [ ]
- Descriptive statistics per building
- Correlation between energy variables
- Correlation between energy and weather
- Seasonal/diurnal patterns

### Phase 4: Clustering Analysis [ ]
- Cluster buildings by load profiles
- Identify building archetypes

### Phase 5: Figures & Report [ ]
- Generate all figures as PNG
- Write report/report.md
